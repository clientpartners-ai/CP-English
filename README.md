# CP-English — Client Partners English Site

Client Partners（クライアントパートナーズ）の英語サイト用テンプレート・CSS・ページ群。

Movable Type（MT）上で運用されており、このリポジトリはテンプレートとCSSのバージョン管理・ClaudeCode/TeamAgentによる継続開発のために使用する。

---

## 📁 ディレクトリ構成

```
CP-English/
├── README.md               # このファイル
├── CLAUDE.md               # ClaudeCode向け引き継ぎ情報
├── templates/
│   ├── layout_module.html      # 共通レイアウト（ヘッダー・フッター）
│   ├── index.html              # トップページ
│   ├── contact.html            # お問い合わせページ
│   ├── access.html             # アクセスページ
│   ├── rent-a-family.html      # Rent-a-Familyページ
│   ├── rent-a-friend.html      # Rent-a-Friendページ
│   ├── ok-grandma.html         # OK Grandmaページ
│   └── privacy-policy.html     # プライバシーポリシーページ
└── assets/
    └── css/
        └── style.css           # メインCSS（MTの[CSS]テンプレートに貼り付ける）
```

---

## 🛠️ 技術スタック

- **CMS**: Movable Type（MT）
- **CSS**: カスタムCSS（`assets/css/style.css`）
- **フォント**: Noto Sans JP（本文）、Poppins（英語見出し）、grandam（装飾用・筆記体）
- **アイコン**: Material Icons
- **ホスティング**: `https://www.clientpartners.jp/english/`
