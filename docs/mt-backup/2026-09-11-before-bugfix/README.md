ユーザーがMT管理画面からコピーした実物を保存しています。

| ファイル | MTテンプレート名 |
|---|---|
| `layout_module.html` | En 共通レイアウト |

## 使い方（ロールバック手順）

バグ修正版を反映して問題が起きた場合、このフォルダの各ファイルを
MT管理画面の対応テンプレートに全文貼り付け → 保存 → サイト再構築で
反映前の状態に戻せます。
