## Phase 1: サイト完成（最優先）

> 目標: 全ページが正常に表示され、一般公開できる状態にする

### Step 1-3: コンテンツ精査

| タスク | 担当 | 詳細 |
|---|---|---|

### Step 1-4: 素材の準備

| タスク | 担当 | 詳細 |
|---|---|---|
| 必要画像リスト提出 | Agent (Asset Mgr) | ファイル名・サイズ・用途の一覧 |

## 作業の流れ（日常運用）

```
1. Agent が作業 → GitHub にプッシュ → PR作成
2. 人間が PR を確認 → 承認
3. main にマージ
4. 人間が MT管理画面でテンプレート更新 → 再構築
5. 本番で確認 → 完了
```

## リポジトリ公開設定について

現在 **Public**（誰でも閲覧可能）です。

検討事項:
- テンプレートや翻訳テキストは公開情報なのでリスクは低い
- ただし `.gitignore` 外の情報が意図せず公開されるリスクはある
- Private にすれば外部からのアクセスを遮断できる
- **判断は Phase 2 までに行う**（公開前に決定）
